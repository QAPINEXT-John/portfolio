Politique de confidentialité

Dernière mise à jour : 16 octobre 2026

Responsable du traitement

John Venien — john.venien@efrei.net.

Données collectées par le site

  • Aucun formulaire : le site ne demande aucune information.
  • Aucun cookie et aucun outil de mesure d’audience.
  • Aucune ressource externe : la police, les icônes et les scripts sont hébergés sur le site ; aucune requête n’est envoyée à Google Fonts, à un CDN ou à un autre service.

Données traitées par l’hébergeur

GitHub enregistre l’adresse IP des visiteurs à des fins de sécurité, que le visiteur ait un compte GitHub ou non. Ce traitement relève de GitHub : voir la déclaration de confidentialité de GitHub.

Messages envoyés par e-mail

Si vous écrivez à l’adresse de contact, votre message et votre adresse ne servent qu’à vous répondre. Ils ne sont transmis à personne et sont supprimés quand l’échange est terminé.

Vos droits

Conformément au Règlement général sur la protection des données (RGPD), vous disposez d’un droit d’accès, de rectification, d’effacement et d’opposition sur les données vous concernant. Écrivez à l’adresse de contact. Vous pouvez aussi adresser une réclamation à la CNIL (cnil.fr).

Données de l’auteur publiées sur le site

Le site publie volontairement le nom de l’auteur, son adresse e-mail étudiante et un lien vers son profil GitHub. Aucune adresse postale ni aucun numéro de téléphone n’est publié.
