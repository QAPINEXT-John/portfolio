# Portfolio BTS SIO SLAM — John Venien

Portfolio personnel pour l'épreuve E5 du BTS SIO (option SLAM), Efrei Paris.
Site statique en HTML et CSS, versionné avec Git et publié avec GitHub Pages.

- Site en ligne : https://qapinext-john.github.io/portfolio/
- Maquette Figma : https://www.figma.com/design/ATCPlZt3jJWBAGwDmIhdnL/Portfolio-John-Venien---Maquette

## Organisation

| Fichier | Rôle |
|---|---|
| `index.html` | Accueil |
| `parcours.html`, `competences.html`, `projets.html`, `veille.html`, `contact.html` | Pages du menu |
| `realisation-environnement.html` | Fiche réalisation |
| `mentions-legales.html`, `confidentialite.html` | Pages légales (LCEN, RGPD) |
| `css/style.css` | Ma feuille de style : charte graphique, mise en page, états survol/focus, media queries |
| `css/theme-personal.css` | Thème Start Bootstrap « Personal » (inclut Bootstrap 5) |
| `fonts/`, `vendor/` | Police Rubik, Bootstrap Icons et JavaScript de Bootstrap, hébergés sur le site |

Aucune ressource externe n'est chargée (pas de Google Fonts ni de CDN) : aucune donnée des visiteurs n'est envoyée à un tiers.
